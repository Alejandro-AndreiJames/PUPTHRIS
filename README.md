# PUPTHRIS (Faculty Evaluation, Information, and Research System)

PUPTHRIS is a centralized web application built to streamline and modernize academic administration. The platform manages comprehensive faculty profiles, automates performance evaluation cycles, and serves as a secure repository for institutional research. 

---

## 🛠️ Core Features & System Modules

### 1. Faculty Information Management
* **Comprehensive Profiles:** Centralizes academic background, employment history, certifications, and teaching loads into unified digital records.
* **Dynamic Search & Filtering:** Allows administrative staff to instantly query faculty databases by department, specialization, or rank.

### 2. Automated Evaluation Engine
* **Multi-Stakeholder Feedback:** Facilitates structured performance evaluations completed by students, peers, and supervisors.
* **Performance Analytics:** Consolidates assessment metrics into readable data summaries to help administration track performance trends over time.

### 3. Research & Publication Repository
* **Academic Archiving:** Provides a dedicated space for faculty to upload, categorize, and track research papers, journals, and project milestones.
* **Accessibility Controls:** Ensures research metadata is searchable while maintaining secure data access permissions.

### 4. Inclusive & Accessible UI/UX
* **Simplified Navigation:** Engineered with high-contrast elements, straightforward menus, and clear workflows designed to be fully accessible for non-technical and elderly users.
* **Responsive Architecture:** Fully optimized for seamless operation across desktop monitors, laptops, and mobile tablet layouts.

---

## 🏗️ Technical Architecture

### Front-End (Client Side)
* **Framework:** Angular
* **Design System:** TailwindCSS & DaisyUI (Responsive, utility-first components)
* **State & Routing:** Client-side routing for seamless, low-latency navigation.

### Back-End (Server Side)
* **Runtime Environment:** Node.js
* **Framework:** Express.js (RESTful API architecture)
* **Database Management:** MySQL (Relational schema designed for transactional integrity)

### Infrastructure & Hosting
* **Cloud Platform:** Amazon Web Services (AWS)
* **Compute Instance:** AWS EC2 (Highly available server hosting)
